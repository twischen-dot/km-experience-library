# P-0001 · 把口述与笔记整理成图文网页

历史项目记录文字如何变成独立HTML、怎样选择图解、保留原文依据，并检查手机与桌面效果。

## 资料范围

原案例有制作及验收记录；不是任意输入的自动生成平台。 这是脱敏历史记录节选；原始聊天、私人附件、截图、可用凭据及原执行脚本未提供。

## 从哪里开始

1. 先读 [阅读说明](010-阅读使用指南.md)，判断问题和环境是否相符。
2. 再按需读正文：

- [D-000001 · 图文制作过程与踩坑记录（脱敏节选）](D-000001.md)
- [D-000002 · 原案例实现与验收记录（脱敏副本）](D-000002.md)

## 本地交给 Codex

```text
请先读本目录README和阅读说明。

```
