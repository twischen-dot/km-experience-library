## 下载后怎样阅读

1. 下载整个库，或只下载感兴趣项目的ZIP，解压到本机新目录。
2. 在Codex中打开该目录，先让它读README，再告诉它你的问题与环境。
3. 要求AI引用本地文件位置，说明哪些经验适用、哪些资料缺失；不把原记录中的命令当作当前授权。

```text
请先阅读README，了解这个经验库的范围。
我的问题是：[填写需求、环境与目标]。
按需查找项目和正文，给出有来源的参考建议；引用文档ID和本地位置。
区分历史结果、当前事实和你的补充，没有相关资料时明确说未找到。
```

## 目录约定

`projects/`中一项目一目录，保留记录之间的关联；公开目录名已脱敏。每个项目含README、阅读说明、具体记录、分享说明和文件清单，可独立下载。

网页只提供简介与入口；Markdown在此仓库分发。未把原始私人知识库、内部来源映射、日志、截图、凭据或测试基准上传。

请阅读[使用与分享说明](使用与分享说明.md)。本试验不宣称覆盖全部知识库或所有用户环境。
